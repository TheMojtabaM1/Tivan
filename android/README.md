# TIVAN Controller (Android)

اپلیکیشن اندروید برای کنترل کامل دستگاه دزدگیر/رله‌ی پیامکی **TIVAN S44T** از طریق پیامک (SMS) — بدون نیاز به اینترنت
روی گوشی، طبق راهنمای رسمی دستگاه.

## قابلیت‌ها
- مدیریت چند دستگاه (چند شماره سیم‌کارت ذخیره‌شده و قابل سوییچ)
- کنترل ۴ خروجی: روشن/خاموش/تایمر ثانیه‌ای و دقیقه‌ای/نام‌گذاری
- حالت دزدگیر: فعال/غیرفعال، تک‌زون یا دو زون
- گزارش‌گیری وضعیت ورودی/خروجی، آنتن‌دهی، دما و شارژ سیم‌کارت
- تنظیمات پیشرفته: مدیران فرعی و کاربران، سنسور دما و ترموستات A/B، ریموت کنترل، مد ورودی‌ها، پیام‌های سفارشی، بیزر، حافظه خروجی، تک‌زنگ (MISSED)، تاخیر در وصل خروجی‌ها، ارسال دستور دستی خام
- دریافت خودکار پیامک‌های دستگاه و نمایش در تاریخچه

## نیازمندی‌ها
- Android 7.0 (API 24) به بالا
- مجوز SEND_SMS / RECEIVE_SMS / READ_SMS

## بیلد
این پروژه از طریق GitHub Actions (`.github/workflows/android-build.yml`) به‌صورت خودکار بیلد می‌شود و APK دیباگ
به‌عنوان Artifact در تب Actions هر ران در دسترس است. نیازی به نصب Android Studio یا Gradle روی سیستم شخصی نیست.

برای بیلد محلی (اختیاری، در صورت داشتن Android Studio):
```
cd android
./gradlew assembleDebug
```
